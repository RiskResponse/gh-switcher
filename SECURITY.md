# Security Policy

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/RiskResponse/gh-switcher/security/advisories/new),
not in public issues or pull requests.

Include the affected version or commit, steps to reproduce, and the impact you expect. We aim to acknowledge reports
within a few business days.

gh-switch changes which GitHub account `gh` and git use on your Mac, so reports about the MCP server (`gh-switch mcp`),
account switching or removal, and the files it writes (`~/.config/gh-switch/config.json`, `~/.gitconfig`,
Claude's `claude_desktop_config.json`) are especially welcome.
